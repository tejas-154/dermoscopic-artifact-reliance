# Controlled Dose-Response Characterization of Synthetic Artifact Reliance in Dermoscopic Lesion Classification

Code and analysis materials accompanying the manuscript:

**Controlled Dose-Response Characterization of Synthetic Artifact Reliance in Dermoscopic Lesion Classification**

This repository contains the experimental and analysis code used to evaluate controlled artifact–label association, artifact reliance, attribution validation, robustness analyses, boundary-condition analyses, architecture replication, natural-hair analysis, and external replication.

## Data availability

The underlying dermoscopic image datasets are not redistributed in this repository. Dataset access remains subject to the terms and conditions of the respective dataset providers.

## Code

The repository contains the analysis notebooks used for the reported experiments and statistical analyses.

## Reproducibility

The analyses were conducted using the experimental protocols described in the accompanying manuscript. Trained model checkpoints and underlying datasets are not included in this repository.
